## ✨ Features

<details open>
<summary><b>🏠 Hero / Landing</b></summary>

- Animated gradient background, subtle and lightweight
- Typewriter tagline cycling through "Software Developer" → "Full-Stack Developer" → "AI Enthusiast" → "Problem Solver"
- Fade-in / slide-up entrance animation on load
- CTA buttons: *View My Work* · *Download CV*

</details>

<details>
<summary><b>🃏 Animated Project Cards</b></summary>

- 3D flip-card animation on hover/tap — front shows title + tech stack, back reveals full description + live link
- Pure CSS, GPU-accelerated — zero impact on load time

</details>

<details>
<summary><b>📬 Working Contact Form</b></summary>

- Delivers messages directly to inbox (Formspree/EmailJS backend — not just `mailto:`)
- Click-to-call phone number (`tel:` link opens dialer instantly)
- Animated success/error confirmation

</details>

<details>
<summary><b>⚡ Performance & Accessibility</b></summary>

- Lazy-loaded images, compressed assets, no render-blocking scripts
- Fully responsive across mobile / tablet / desktop
- Semantic HTML, alt text, keyboard-navigable nav & form
- SEO meta tags + Open Graph configured

</details>
